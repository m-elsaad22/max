# تقرير فحص موقع ماكس آرت

**الموقع:** https://max-art-ae.com  
**تاريخ الفحص:** 16 سبتمبر 2026  
**القالب النشط:** KAYAN Theme `kayan-theme` 2.4.7  
**ووردبريس:** 7.1 / PHP 8.3.19  
**طريقة الفحص:** الواجهة العامة + WordPress REST + WPVibe/WP-CLI + قراءة ملفات القالب الحي + تصفّح المتصفح (سطح المكتب والجوال)

الخلاصة: الصفحة الرئيسية تبدو مكتملة تسويقياً، لكن الموقع من الداخل غير مكتمل، وفيه أعطال قاتلة للـ SEO والثقة والتحويل. كثير من البنية موروث من منصة «ركن التطور / KAYAN» متعددة الدول، ولم تُنقَّ إن لموقع إماراتي واحد.

التقدير الإجمالي للموقع الحي: **4 / 10** (واجهة رئيسية 6، محتوى 3، قالب تقني 3، SEO 2، ثقة/قانوني 2).

## أ. أعطال حرجة (تُصلَح فوراً)

### 1. صفحات 404 تتحول إلى الرئيسية (302) — كارثة SEO
القالب `components/packs/@404/shape.php` يحتوي سطراً واحداً:

```php
wp_redirect( home_url() );
```

أي رابط غير موجود يُرجع `302` إلى `/` بدل `404`. جُرّب:

- `/this-page-does-not-exist-audit-404/` → 302 إلى الرئيسية
- `/south-creek-plumbing/` وبقية روابط السباكة الأمريكية في خريطة MPG → 302
- `/contact/` و`/about/` و`/contact-us/` → 302

`functions.php` فيه دالة `kayan_send_404_status()` لكن لا تصل للتنفيذ لأن قالب 404 يعيد التوجيه قبلها.

**الأثر:** جوجل يعتبرها soft 404، تضعف الزحف، وتخفي الروابط المكسورة.

### 2. أرشيف الأنواع المخصصة ينهار بخطأ فادح HTTP 500
هذه العناوين تُظهر صفحة ووردبريس البيضاء «كان هناك خطأ فادح في هذا الموقع»:

| الرابط | الحالة |
| --- | --- |
| `/services/` | 500 |
| `/reviews/` | 500 |
| `/faqs/` | 500 |
| `/pricing/` | 500 |
| `/portfolio/` | 500 |
| `/before-after/` | 500 |

السبب في `@archive/default.php`: القالب مبني على **تصنيف** (`$obj->term_id`, `$obj->taxonomy`) ويُستخدم أيضاً لأرشيف نوع المنشور. على PHP 8.3 الوصول لخصائص غير موجودة على `WP_Post_Type` يُسقط الصفحة.

### 3. لا توجد صفحة تواصل — وزر التذييل مكسور
- لا صفحة `من نحن` ولا `اتصل بنا` ولا `المشاريع`.
- تذييل الموقع يربط إلى `/contact-us/` فيُحوَّل إلى الرئيسية.
- القائمة الرئيسية تشير إلى `#services` `#areas` `#projects` `#blog` `#why` `#faq` **وهذه المعرّفات غير موجودة** في HTML الرئيسية. النقر من أي صفحة داخلية لا يصل لقسم حقيقي.

### 4. محتوى مولَّد ينشر أرقام قطر وعلامة «ركن التطور» على موقع إماراتي
عينة المقال `شركة إصلاح تسرب المياه في النعيمية` (ID 2940) وغيره:

- هاتف `tel:+97431110184` وواتساب `97431553076` (قطر) بدل `+971544437175`
- توقيع وهمي: «م. خالد المطيري — شهادة ISO 9001»
- «مراجعة: فريق **ركن التطور**»
- أكثر من 20 مقالاً على الأقل تحتوي الرقم القطري (العداد توقف عند حد 20 في WP-CLI؛ العدد الحقيقي أكبر)
- مئات المقالات نُشرت دفعة واحدة في 11 سبتمبر 2026 خلال دقائق، بنفس الصورة البارزة، وأغلبها في تصنيف «صيانة عامة» (351 مقالاً)

هذا باب doorway/SEO spam، ويضر الثقة القانونية (ادعاء ISO بدون إثبات + هوية شركة أخرى).

### 5. صفحة MPG منشورة للزحف بنص غير مستبدل
`/mpg_citys-expert-plumbing-services/` مفهرسة (`index, follow`) وعنوانها:

`{{mpg_city}}'s Expert Plumbing Services`

في المتصفح ينقلب العنوان بسبب RTL إلى: **S Expert Plumbing Services'{{Mpg_city}}**. والمتن الإنجليزي كله يظهر القوالب `{{mpg_city}}` / `{{mpg_state_name}}` / `{{mpg_company}}` كما هي.

إضافة Multiple Pages Generator **غير مفعّلة**، لكن الصفحة بقيت منشورة.

### 6. `robots.txt` يوجّه جوجل إلى خريطة سباكة أمريكية
محتوى robots.txt بالكامل:

```
User-agent: *
Allow: /
Sitemap: https://max-art-ae.com/mpg-sitemap-plumbing-services.xml
```

خريطة MPG تسرد مدناً أمريكية مثل `south-creek-plumbing` و`sierra-madre-plumbing` و`fort-atkinson-plumbing`. هذه الصفحات غير موجودة (302 للرئيسية).

خريطة Rank Math الفعلية `sitemap_index.xml` **غير مذكورة** في robots.txt، وتحتوي منشورات فقط (لا صفحات، لا خدمات).

`/sitemap.xml` ملف قديم فيه:

- `/legal-notice` (غير موجود)
- `/privacy`
- `/subpage` (غير موجود)

## ب. نواقص المحتوى والبنية (الموقع غير مكتمل)

### الصفحات الموجودة فعلياً
ثلاث صفحات فقط:

| الصفحة | المشكلة |
| --- | --- |
| الرئيسية (تدوينات، ليست صفحة ثابتة) | `show_on_front = posts` |
| Blog | العنوان والإنجليزي H1: `Blog` |
| Privacy Policy | نص ووردبريس الافتراضي بالإنجليزية: *Suggested text: Our website address is…* |
| MPG placeholder | قوالب `{{mpg_*}}` |

لا توجد: من نحن، تواصل، مشاريع/معرض، أسعار حقيقية، سياسة كوكيز عربية، شروط الخدمة.

### الخدمات
الموقع يدّعي **34 خدمة** في الواجهة. في ووردبريس:

- CPT `services`: **خدمتان فقط** (`كشف تسربات المياه`، `عزل أسطح`)
- صفحة الخدمة «عزل أسطح» فيها مستند HTML/CSS كامل ملصوق داخل المحتوى (`* { margin:0 }`, `:root { --pepsi-blue }`). في المتصفح الصفحة شبه **بيضاء فارغة** (الهيدر فقط + شريط جانبي باهت) لأن الـ CSS الملتصق يصفر الصفحة.
- صفحة «كشف تسربات»: هيرو أزرق فارغ بمساحة كبيرة، بطاقة تواصل بحقول فارغة، وفي قسم الخدمات المرتبطة يظهر كود CSS كنص: `--root { --royal-blue… --pepsi-b…` بعنوان «عزل أسطح». بلا meta description.
- تصنيف `service_categories` فيه عنصر واحد بعدّاد 0
- قسم التذييل «أهم خدماتنا» قائمة **فارغة** `<ul></ul>`

### المدن / التغطية
الواجهة: 10 مناطق بما فيها خورفكان ودبا.  
التصنيف `cities`: 8 مدن، **معظمها count = 0**.

- دبي slug مُرمَّز خطأ: `%d8%af%d8%a8%d9%8a` بدل `dubai`
- الفجيرة slug: `fujirah` (خطأ إملائي)
- لا أرشيف مدينة يعمل: `/dubai/` و`/cities/dubai/` → 302 للرئيسية
- لا صفحات مدينة/خدمة (الـ pSEO الحالي مقالات مدونة بأسلگات `shrkh-aslah-tsrb-almyah-fy-...`)

### التقييمات / الأسعار / الأعمال السابقة / الأسئلة
الأنواع موجودة ومفرداتها منشورة، لكن الصفحات شبه فارغة: **لا H1**، لا محتوى خاص، فقط «مقالات ذات صلة» من مقالات التسريب + نموذج تقييم عام بلا تعليقات.

### المدونة
- عنوان الصفحة إنجليزي
- المقالات الحديثة كلها تقريباً قالب واحد: تسريب مياه + حي إماراتي
- نفس المؤلف الوهمي ونفس الصورة
- لا استراتيجية محتوى لخدمات الحديد/المظلات/البرجولات المعلن عنها في الهيرو

### نموذج الطلب في الرئيسية
مكوّن `ruknfinder` يختار خدمة + إمارة ثم يفتح واتساب فقط.

- ليس `<form>` ولا يحفظ الطلب في ووردبريس
- أوقات الاستجابة لكل المدن نص واحد: «يُحدَّد عند التواصل»
- لا حقل اسم/هاتف/موقع داخل الموقع
- أزرار `tel:` و`https://wa.me/` فارغة في مواضع أخرى من القالب

## د. أخطاء القالب (KAYAN / YourColor)

### بنية القوالب الناقصة
ووردبريس يسجّل القالب بلا: `single.php`, `page.php`, `archive.php`, `404.php`, `search.php`. الاعتماد كله على `ThemeStatic::Locate()` ثم `die()`.

### أخطاء برمجية مؤكدة في الملفات المقروءة

1. **`functions.php`**
   - `TempURL = get_template_directory()` (مسار ملفات) بدل URI
   - ترتيب خاطئ لـ `__()`: `__($name, 'yourcolor', 'post type general name')` — النص الثالث يُتجاهل والنطاق في المكان الخطأ
   - `ob_start()` عند التحميل + حذف `wp_ob_end_flush_all`
   - `wp_reset_query()` في `functions.php` عند كل طلب
   - `@ini_set` لحجم الرفع
   - Text Domain ما زال `yourcolor` (بقايا الثيم القديم)

2. **`syntax.php`**
   - تحويل `?s=` إلى `/search/` يدوياً
   - عند كل زيارة لمقال: كتابة `term_meta views` و`post_meta trending` — تعارض مع الكاش ويبطئ الموقع
   - `die()` بعد الرسم فيكسر shutdown لإضافات الكاش/الإحصاء

3. **`@search/shape.php`**
   - بحث SQL مباشر على العنوان فقط (لا المحتوى، لا الخدمات)
   - عند لا نتائج: `print_r($myposts); print(1);` — بقايا تصحيح تظهر للزائر
   - أخطاء إملائية: «علي» بدل «على»، «الالمقالات»

4. **`@archive/default.php`**
   - لا يدعم أرشيف CPT → 500
   - نصوص: «لن يتم العثور على المقالات اخري» / «لقد شاهدت جميع الالمقالات»

5. **`@page/shape.php`**
   - إذا `SelectedModel` غير موجود يُعيَّن مسار `standard-page.php` **دون `require`** → صفحة فارغة

6. **`@single/shape.php`**
   - يبحث عن قالب حسب `post_type`. الأنواع المخصصة بلا قالب مناسب فتظهر فارغة

7. **جافاسكربت عام للزائر (تذييل الرئيسية)**
   - `var ISMobile = true;` حتى لو الطلب ليس جوال
   - `Currentuser_Logged = true` للزائر غير المسجّل
   - jQuery مرتين: نسخة ووردبريس + `jquery-3.4.1.min.js`
   - Font Awesome CSS يُحمَّل **ثلاث مرات**
   - عدّادات `data-count` تظهر `0` في HTML الخام (جوجل بدون JS يرى صفراً). في المتصفح تتحرّك، لكن `toLocaleString("en-US")` يطبع سنة التأسيس **2,008** بفاصلة إنجليزية في لوحة الهيرو — تبدو كعدد آلاف لا كسنة

8. **منصة دول متعددة على موقع دولة واحدة**
   - `/en/` يرجع نفس العربية (`lang="ar"`) مع `noindex` وبلا canonical
   - `/sa/` و`/qa/` وبقية الدول **200 + index,follow** ومحتوى إماراتي مع علم السعودية — محتوى مكرر قابل للفهرسة
   - محوّل الدولة/اللغة في الهيدر (الإمارات، السعودية، قطر، الكويت، عمان، البحرين، مصر + EN) لا يناسب ماكس آرت

9. **مسارات الحزم `#footer`**
   - `%23footer` في روابط JS بسبب مجلدات تبدأ بـ `#`

## هـ. SEO تقني إضافي

- Rank Math Sitemap: منشورات فقط. لا `page-sitemap` ولا `service-sitemap` (302 للرئيسية).
- لا `hreflang` رغم محوّل لغات.
- الصفحة الرئيسية Schema نوعها `CollectionPage` لأن الرئيسية = تدوينات لا صفحة ثابتة.
- SearchAction في Schema يشير إلى `/?s=` بينما القالب يحوّل إلى `/search/{query}`.
- مقالات pSEO بأسلگات حرفية: `shrkh-aslah-tsrb-almyah-fy-alnaymyh` بدل عناوين واضحة.
- تصنيفات كثيرة slugs مزدوجة الترميز (`%d8%aa%d8%b1...` مخزَّن كنص slug).
- لا صورة Open Graph.
- عنوان الرئيسية مكرر: «شركة ماكس آرت - شركة ماكس آرت للصيانة…»
- صفحات الخدمات بلا description.
- سياسة الخصوصية بالإنجليزية ومفهرسة.
- إضافة Yoast مثبتة وغير مفعّلة بجانب Rank Math (بقايا تعارض محتمل).
- LiteSpeed Cache يعمل؛ مع كتابة meta عند كل مشاهدة المقال الكاش يتضارب مع «trending».

1. **إيقاف النزيف SEO:** صفحة 404 حقيقية؛ حذف/noindex لصفحة MPG؛ تصحيح robots.txt لخريطة Rank Math؛ noindex لمسارات `/sa/` `/qa/`… أو تعطيل راوتر الدول؛ إزالة خريطة السباكة الأمريكية.

7. **هوية:** اسم Schema، شعار صالح، og:image، سوشيال الشركة، إخفاء أرشيف المؤلف.
8. **قالب:** إزالة `die()` غير الضروري، إيقاف الكتابة عند المشاهدة، إصلاح `ISMobile`/`Logged`، حذف jQuery/FA المكرر، text-domain، 404، البحث.
